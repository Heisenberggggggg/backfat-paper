## 1. 课题一句话定义与三层产出

**一句话**：在课题组已有的妊娠母猪精准饲喂站上，加装深度相机与 Jetson 边缘计算单元，实现母猪进站瞬间"身份识别 → 非接触背膘测量 → 动态决策 → 精准下料"的实时闭环，把现有的**开环按曲线饲喂**升级为**体况驱动的闭环饲喂**。

**三层产出（同源不同粒度，需注意口径一致）**

| 层级 | 载体 | 状态 | 关键约束 |
|---|---|---|---|
| 学位论文 | 《基于边缘计算的妊娠母猪背膘测量及闭环饲喂系统设计》（华中农业大学 硕士，导师 朱明，学号 2024307110102） | 开题已过（2025-12-03，新工科楼 G320），进行中 | 四大研究内容需全部落地，含系统联调与对比试验 |
| 期刊论文 | 《农业工程学报》"畜禽健康监测与疫病智能诊断防控技术"专题，方向（4）健康监测技术装备创制及应用 | 初稿已成型，**截稿 2026-08-31**，预计出版 2026-11 | EI 收录、三审三校、绿色通道；需 GB/T 7714 引用格式 |
| 专利 | ①《一种基于 3D 视觉与边缘计算的妊娠母猪闭环精准饲喂系统及方法》（系统级，已提交）；②《一种基于 P2 点自动定位与多模态特征融合的母猪背膘非接触测量方法》（算法级，交底书 v2.0 已成稿） | ① 已递交；② 待递交 | 两件构成并列保护关系，形成专利池 |

**核心痛点（贯穿三层的立论支点）**
1. **感知滞后与应激** —— A/B 超接触式测量，周/月级频次，应激大。
2. **算力与实时性矛盾** —— PointNet++/Point Transformer 类模型算力需求高，多跑在服务器上，猪场网络回传延迟高。
3. **测控脱节** —— 现有饲喂站（含课题组前期成果）靠人工录入体况或静态曲线，感知与执行相互割裂，是典型开环。

### 4.5 标签分布特性 ★（全课题最关键的一条数据事实）

- 范围 5–35 mm，**13–19 mm 区间占 57%**，分布高度集中，CV≈0.997
- 存在 70 mm、200 mm 两个明显的记录异常值
- **成因**：猪场本就按妊娠曲线饲喂，母猪体况被人为调控在目标区间附近 —— 这是真实生产数据的**固有特征**，不是采样缺陷
- **后果**：标签方差小 → **R² 被结构性压低**。这是"MAE 可用（2.7–3.7 mm）但 R² 接近 0"这一表观矛盾的根本解释
- **写作策略**：不以 R² 为主指标；主指标用 MAE + 体况分类准确率；R² 照实给并当场解释

## 5. 算法链路与代码地图

### 5.1 当前主流程（论文 1.3 节所写）

```
Azure Kinect DK 俯视 RGB + Depth
   └─ 相机内参像素级对齐
       └─ YOLO11n 检测（取最大 bbox，取消类别过滤；失败时用全图 bbox 兜底）
           └─ FastSAM-s 分割（bbox 作先验，输出像素级二值掩膜）
               └─ 掩膜 × 深度图 + 内参 → 反投影掩膜点云（剔除 >85% 背景点）
                   └─ 后处理：HDBSCAN 聚类（丢最小簇=头部）→ MAD 深度离群滤波(k=3.0) → 体素下采样
                       └─ ★不做单位球归一化，只中心化★
                           └─ 回归 → 背膘厚度 (mm)
```

**关键工程细节（论文中已写、也是专利要点）**
1. YOLO 通用权重会把母猪误判为 **绵羊（COCO 第 18 类）** → 取消类别过滤，取面积最大框。
2. 母猪贴近相机占满画面时检测器失效 → **全图 bbox 兜底**。经此处理测试图像定位成功率 **100% (181/181)**。
3. 俯视下限位栏横杆把猪体切成 3 段：**头 ~13% / 背 ~64% / 臀 ~21%**。丢最小簇=去头。
4. 原始掩膜点云可达 **2.8×10⁵ 点**，直接 HDBSCAN 会 OOM → 先随机降采样到 5000 点（**索引排序保持空间连续性**）。
5. MAD 滤波去除约 **5.9%** 残留栏杆点；HDBSCAN 仅去 **0.9%** 噪声 → **部署时 HDBSCAN 可省略**。

## 7. 已确证的技术结论与踩坑清单

### 7.1 八条核心结论（跨阶段、可写进论文）

1. **单位球归一化是点云回归的隐形杀手**。背膘是绝对物理量，归一化抹除绝对尺度 → 模型退化为均值预测。所有用归一化数据的实验 R²≈0；去归一化后同类方法立即恢复到 0.07 以上。
2. **3D 几何信号本征弱于 RGB 纹理信号**。师姐 RGB R²=0.74（106 头）vs 本项目 3D 最优 0.211（912 头）。皮下脂肪厚度与体表三维形状的耦合强度有限；脂肪信息更多体现在皮肤纹理、色泽、局部形变上。
3. **深度图 CNN > 点云直接回归 > 多视角投影**。深度图保留二维拓扑结构，利于卷积提取空间模式；投影因栅格填充率仅 7% 反而丢信息。**该结论已被外部研究独立验证**（见 `02_前沿方法调研`）。
4. **双视角（背+臀）融合无增益甚至有害**。臀部单视角 R²=0.008，融合后 0.058 低于背部单视角 0.067。→ 工程价值：**单俯视相机即可，无需第二路相机与配准开销**。
5. **代码实现无 bug**。多次审计 + 在师兄 146 头数据上复测得 R²=0.14–0.28（与其报道一致）→ 瓶颈在数据与信号，不在实现。
6. **样本量主导，品系不主导**。分品系训练未带来提升；小样本品系（T, 64 头）反而崩盘；全量训练最稳。**"数据多样性 > 品系细分"**。
7. **MAE 稳定在 2.7–3.7 mm**，与业内水平相当（人工 B 超重复测量的操作者间差异同量级），对"偏瘦—正常—偏肥"三分级判别具备实用性。
8. **数据量是首要瓶颈**，其次是标签分布过窄。与其细分子集，不如汇集全部数据。

### 7.2 根本性反思（v4 报告原文，仍然成立）

> 当前 R² 上限（≈0.2）很可能就是**单纯依赖几何数据**的天花板。若追求 R²>0.5，必须：引入 RGB（师姐路线）；或加入体重、年龄、胎次等结构化特征；或从俯视改为侧视获取更直接的几何信号。

**四条创新点**：① P2 点自动定位机制（主权利要求级，对齐 **GB/T 22569-2008** 与 ICAR 规范，可与 PIC/SEGES/PigChamp 育种数据库互通）；② P2 ROI 局部多模态融合回归；③ 面向栏杆物理遮挡的 2D 连通域自适应筛选；④ 全 2D 域轻量化边缘管线。

> ⚠️ **交底书中的性能数字（0.5–1.0 s 时延、30 M 参数）目前是设计目标，尚无实测支撑。** 用于专利可以；写进论文必须实测。
