## 3. 方法框架（每个模块的出处已在 04 核实）

```
两视角 RGB-D 帧序列（俯视 / 斜后视）
  │
  ├─ ① 目标母猪分割：YOLO + FastSAM（现有）→ 可替换 SAM 3            [借鉴]
  ├─ ② 几何标准化：拟合地面 → 离地高度 → 等物理尺度 → 统一朝向        [借鉴 PigFormer，扩展到斜后视]
  ├─ ③ 帧特征：冻结 DINOv2/v3（RGB、深度伪彩）或 ResNet-18             [应用层新：背膘回归中未见]
  ├─ ④ 多帧聚合：质量门控 + 注意力                                     [借鉴肉牛 Episode-MIL]
  ├─ ⑤ 视角融合：两视角特征集合直接融合，免配准、视角随机丢弃          [借鉴 Pig3DNet GVQF；对照胡宝玖 ICP]
  ├─ ⑥ 生产记录先验：胎次 + 妊娠日龄 → 群体先验，视觉学残差（DAFT 调制）[方法借鉴 DAFT；ΔR² 量化为新]
  └─ ⑦ 输出：背膘点估计 + 保形预测区间（90%）→ 区间过宽提示 B 超复测    [新：畜禽表型中未见]
```

**真正可主张的创新点（4 条，均写「据检索所及」）**
1. **表型数据治理**：多季重复测定下按耳号子串匹配导致约 1/3 标签错配；纠正后 R² 0.083 → 0.297（同模型同划分）。
2. **统一评估协议下的前期方法重评**：量化测试集选模造成的偏差，为本领域小样本研究提供可复现基准。
3. **视觉相对生产记录的增量信息（ΔR²）**：回答「已有胎次、日龄记录时，看图还能多解释多少背膘变异」。
4. **带覆盖率保证的表型区间 + 复测分流**：给出可节省多少 B 超测定的量化曲线。

免配准双视角融合、可部署管线写成方法改进，不单列为创新点。

| 要报的 | 来源 |
|---|---|
| 分阶段时延（检测 / 分割 / 高度图 / 回归）、FPS、显存、功耗 | `edge_deploy/edge_profile.py`，换最终模型重测；26.8 实测旧模型稳态约 60–75 ms/帧（首帧约 1 s 为冷启动） |

**不写**：剪枝、INT8 量化等没做的实验；不把部署写成主创新。

### 4.2 饲喂站 —— 只作应用场景

- 一段文字 + 一张总装图，**引用尹珂、宣胺文学位论文**，明确为课题组前期平台。
- 「背膘 → 动态调整饲喂量」的闭环**没有生物学验证**，本文只在讨论中提一句展望，**完整闭环留给学位论文**。
- 原因：gComm 是基因组学刊物，读者关心表型的准确性与可用性；装备与闭环控制放进来会稀释主线，也增加查重风险（电控、结构部分与前期论文高度重合）。

## 8. 算法补充（2026-10-10 讨论）

> 判断：瓶颈在标签与信号（丰美禾标签 SD≈3.9 mm，R² 0.297），不在网络容量；约 820 个标签 vs 约 30 万帧，不上更大的监督网络。标「需查新」的只在写「据检索所及」前做定向检索。

### 8.1 因品系信息新增的评估要求（必做）
