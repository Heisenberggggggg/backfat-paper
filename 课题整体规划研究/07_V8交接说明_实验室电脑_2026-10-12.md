## 4. 要跑的三种协议

**共同约定**：猪级预测 = 该猪 90 帧预测的**中位数**（与胡宝玖一致；另报均值作对照）；指标 MAE / RMSE / R² / Lin CCC / Spearman + 训练集均值基线；3 个种子（42 / 43 / 44）有时间就做，至少 seed 42。**不修改胡宝玖的原文件**：新脚本 import 他的模型类和数据类。

| # | 协议 | 划分 | 选 epoch 的依据 | 目的 |
|---|---|---|---|---|
| P1 | 原样复现 | 原 train 117 / test 15（vaild 不用） | test loss（原代码，含 `.long()`） | 对照原论文报告值，确认复现成功 |
| P2 | 原划分 + 验证集选模 | train 117 / vaild 14 / test 15 | vaild loss（浮点标签） | 同一划分下，只换选模依据 → 直接量化「测试集选模」的乐观偏差 |
| P3 | **本文协议** | 146 头按猪 5 折（StratifiedGroupKFold，按背膘 5 分位分层，shuffle，seed 42）；每折训练集内再留约 1/7 头做验证集 | 验证集 loss；测试折只用一次 | 与丰美禾结果同一协议，进 Table 2 |

**建议实现**：每折训练一次，**逐 epoch 同时记录验证集和测试集的猪级指标**（`epoch_curve.csv`）。这样同一次训练里可以同时得到：按验证集选的 epoch（无偏）和按测试集选的 epoch（乐观上界），差值就是选模偏差，不用重复训练。15 头测试集的指标波动很大，P1 / P2 建议报多个种子的均值 ± SD。
