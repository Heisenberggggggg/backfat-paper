## 记录规范

### 决策日志条目格式（追加到 `DECISIONS.md`）

```markdown
## YYYY-MM-DD ｜ 议题标题

**背景**：为什么要讨论这件事
**参与**：本人 / 导师 / AI
**选项**：列出考虑过的方案（含被否决的，写明否决理由）
**结论**：定了什么
**影响**：需要改动哪些文件 / 哪些实验要重跑 / 哪些论文口径要调
**待办**：可执行的下一步
```

### 三条硬约定

1. **数字必须可追溯**。任何写进这里的实验数字，都要能指向具体的 `training_log*.txt` 或 `test_preds.npz`。存疑的数字标 `〔待核〕`。
2. **不覆盖历史**。调研文件按日期新建，不原地改写；主文件 `01_` 可以修订，但重大口径变更要在 `DECISIONS.md` 留痕。
3. **冲突时以 `01_` 为准**。`01_` 已核对过磁盘实况；与 `PROJECT_REPORT_v4` 不一致时以 `01_` 为准。
