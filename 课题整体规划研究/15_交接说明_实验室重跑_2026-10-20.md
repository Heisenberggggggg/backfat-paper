### 2.5 正式运行

```
python v6o_rerun_subset.py --gpu-jobs 3
```

- 共 40 步，分 5 轮。笔记本 4060 串行约 9.6 h；5090 上 3 路并行，预计 **1.5–3 h**（首轮实测后再估）。
- 进度：`runs_v6o\_driver\driver_log.txt`（START / DONE / FAIL）；每步输出在 `_driver\logs\<步骤>.txt`。
- 中断后：再运行同一条命令即可，已完成的步骤跳过；训练脚本按种子存了断点（`_seed_ckpt`），会从断点续跑。
- 显存：每个训练进程约 2–4 GB，3 路并行足够；不要再加其他 GPU 任务。
- **TabPFN 只用 GPU**（同特征同种子 CPU 与 GPU 差 0.02–0.03 R²，与论文里的增量同量级）。

### 2.6 出错时

1. 先读 `_driver\logs\<步骤>.txt`。
2. 环境问题（缺包、版本）：修环境，然后 `python v6o_rerun_subset.py --redo <步骤>`。
3. 代码问题：只允许**不改变分析含义**的最小修改，例如新版 numpy / pandas / torch 的 API 变化。
   - 每处修改记到 `runs_v6o\_driver\lab_notes.md`：文件:行号、原因、改了什么；
   - 改选模、损失、折、样本、指标等会改变数字含义的地方：**先停下问本人**。
4. 不要动：`runs\`（旧结果）、`runs_v6o\_seed\`、`index_v2.csv`、`v6o_exclusions.csv`、`v6o_label_fixes.csv`。
