## 2. 论文思路（故事线）

**问题**
- B 超测背膘需要接触、熟练操作、逐头测定；
- 体况卡尺快，但读数离散、依赖品系、高体况端有天花板；
- 已有图像方法有三个问题：多用近距离臀部视角；裁剪深度图丢失绝对体尺；评估协议偏乐观。

**方法**
- 限位栏上方一台俯视深度相机；
- 拟合地面 → 物理尺度高度图（7.8 mm/像素，保留绝对体尺）；
- 解剖引导网络：像卡尺一样沿体长读取 16 条背部横截面，再用位置注意力汇总；
- 严格评估：按个体分组 5 折、内层验证选 epoch、多种子、嵌套堆叠、同口径配对比较（bootstrap + Wilcoxon）。

**发现**（对应 Results 各节；贡献 C1–C5）

| 节 | 结论 | 关键数字 |
|---|---|---|
| 3.1 表示（C1） | 高度图优于裁剪深度图；增益在品系内最大 | R² 0.309 → 0.378（+0.069，p=0.001）；丹系头胎 0.158 → 0.268 |
| 3.2 网络（C2） | 精度与基线相当，但注意力自己集中在最后肋骨 / P2 附近 → 可解释 | 0.375 vs 0.370（n.s.）；体长 61%–72% 处权重 0.14 / 0.19 / 0.15（均匀为 0.0625）；MIL 是负结果 |
| 3.3 视角 | 单台俯视相机足够 | 双视角高度图 0.382 vs 0.378（+0.004，n.s.）；两视角残差 r 0.92 / 0.97 |
| 3.4 卡尺（C3） | 相机优于人工卡尺，两者部分互补；卡尺依赖品系、有天花板；虚拟卡尺能在图像上复现卡尺 | 0.375 vs 0.205（+0.171）；卡尺 + 图像 + 几何 0.435；同读数新美系背膘高 1.6 mm；虚拟卡尺与人工 r 0.69 |
| 3.5 可靠性（C4） | 重复性高；预测向均值收缩，误差随背膘水平变化；区间需按品系校准；不确定性挑不出测不准的猪 | ICC 0.73，3.3 帧达 0.90 信度；校准斜率 0.37；≤ 13 mm 高估 3.2 mm、≥ 26 mm 低估 6.1 mm；90% 区间覆盖 0.897、宽 9.7 mm，新美系 0.862 → 0.899；复测分流与随机无差别 |
| 3.6 部署（C5） | 可在边缘设备上实时运行 | Jetson Orin NX：每头猪 3.2 s（TensorRT），约 1 100 头 / h，12.5 W；与离线管线差 ≤ 0.34 mm |

**讨论要点**（稿件 §4 提纲 8 点）
1. 主要发现；
2. 高度图为何有效；
3. 与文献数值的差异（采集距离、视角、评估协议）；
4. 单 / 多视角；
5. 卡尺；
6. 可靠性与不确定性（区间 9.7 mm 适合群体筛查与分级，不适合单头精确测量）；
7. 局限（单场、品系与胎次混杂、向均值收缩、B 超本身误差、跨日重复性未测）；
8. 部署（瓶颈在分割和 CPU 处理；少取帧可加速，属推算）。
