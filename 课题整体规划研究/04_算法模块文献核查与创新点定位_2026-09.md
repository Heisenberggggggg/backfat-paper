# 算法模块文献核查与创新点定位

> 调研日期：2026-09-29
> 起因：9/28 提出的 DV-MIL 框架（几何标准化 / DINOv3 / 帧级注意力 MIL / 免配准双视角交叉注意力 / FiLM 生理先验 / 不确定性 + 排序损失）**是基于通用 ML 知识与 02 号调研拼出来的，未做针对性查新**。本文件逐模块查先例，决定每个模块写成「借鉴 XX」还是「创新点」。

## 0. 结论先行

| 模块 | 先例 | 定位 |
|---|---|---|
| ① 标准化高度图 | PigFormer（arXiv:2606.05611，俯视） | **借鉴**；推广到斜后视是增量 |
| ② 冻结基础模型特征（DINOv2/v3） | 牧草生物量 DINOv3+LoRA（Sensors 2026）、Pig3DNet 用 DINO 回归形状参数（AIIA 2026）；**未检索到用于背膘/体况回归的工作** | **应用层新颖**（写「据检索所及」，不写「首次」） |
| ③ 帧级注意力 MIL + 质量门控 | **肉牛 RGB-D 体况评分：Episode 级注意力 MIL + 几何质量门控**（Animals 2026, 16(19):3040，代码已开源） | **借鉴**，不能当创新点 |
| ④ 多视角加权融合 | Pig3DNet 的 GVQF「几何驱动视角质量评估与融合」（AIIA 2026）；奶牛三相机集成（Sensors 2023）；SAM 3D 一致性融合（arXiv:2601.17791） | **借鉴**；「免配准 + 视角随机丢弃 + 与胡宝玖 ICP 配准对照」只算弱创新 |
| ⑤ 生理先验（胎次/日龄）调制图像特征 | 方法：FiLM（AAAI 2018）、**DAFT**（MICCAI 2021 / NeuroImage 2022）；领域：纯表格 ML 预测妊娠母猪背膘（Peng et al. 2025，RMSE≈1 mm，含历史背膘） | 方法**借鉴 DAFT**；「视觉相对生产记录的**增量信息量**」在背膘领域未见 → **可作创新点（§3.1）** |
| ⑥a 排序 / 有序损失 | Rank-N-Contrast（NeurIPS 2023）；奶牛 BCS 自适应有序度量学习（SIViP 2026） | **借鉴** |
| ⑥b 不确定性 / 保形预测 | **畜禽表型回归中未检索到保形预测（conformal prediction）** | **可作创新点（§3.2）** |
| 跨场迁移 | 奶牛体重：大场→小场迁移学习（Wang et al., arXiv:2601.01044） | **借鉴** |
| 标签质量审计 | 未见背膘/体况领域对「标签匹配错误」做量化的工作 | **数据贡献**（本课题 9/28 发现，R² 0.08→0.30） |

**一句话**：原框架 6 个模块里，**3 个有直接先例**（③④⑥a），2 个方法有先例但应用可新（②⑤），真正空白的只有「保形预测给出表型可信区间」和「量化视觉相对生产记录的增量信息」。创新点必须重新组织。

## 1. 逐方向检索结果

### 1.1 多帧聚合 / 注意力 MIL（方向 1）

| 工作 | 要点 | 与本课题关系 |
|---|---|---|
| **Quality-Gated Episode-Level RGB-D BCS in Beef Cattle**, *Animals* 2026, 16(19):3040；代码 github.com/sxaucao/Episode-Level_Beef_Cattle_Body_Condition_Scoring_with_RGB-D | 同一头牛通过成像区的 RGB-D 多帧视为一个 Episode（包），**注意力 MIL 聚合**；**几何质量门控**按躯干完整度、姿态适宜度、背线连续性、横截面角可计算性筛帧；平均保留 73.45% 帧；5 类 BCS 准确率 61.66%、QWK 0.634；消融证实 RGB 与深度互补、多帧聚合有效 | **③ 的直接先例**。只能写「借鉴其 Episode-MIL 与质量门控思想，迁移到母猪背膘连续回归」 |
| PigFormer（arXiv:2606.05611） | 训练每猪每 epoch 随机 1 帧，推理对全部帧取平均 | 简单平均的基线 |
| 奶牛视频 BCS（YOLOv5 + 视频分析，AIIA 2025）；30 帧时序模型优于 LSTM/C3D | 时序聚合 | 相关工作 |
| Pig3DNet 专利（CN122115788A） | 「聚合多帧测量抑制单帧噪声」 | 多帧聚合是通行做法 |

### 1.2 基础模型用于畜禽表型回归（方向 2）

| 工作 | 要点 |
|---|---|
| **Pig3DNet**, *Artificial Intelligence in Agriculture* 2026, doi:10.1016/j.aiia.2026.05.008 | 用 **DINO 特征 + MLP** 回归猪专用参数化模型 Pig3D（基于 SMAL 改造）的形状与姿态参数；多视角 RGB；尺度恢复需标定相机；体长、臀高 MAE < 2.4 cm |
| Dynamic LoRA Fine-Tuning of **DINOv3** for Pasture Biomass, *Sensors* 2026, 26(16):5285 | DINOv3 + 按层深度递增的 LoRA 做多输出回归 → 农业回归可用 |
| Foundation vision models in agriculture: DINOv2, LoRA and KD（CEA 2025） | DINOv2 + LoRA + 蒸馏用于病害/杂草（分类） |
| Do Foundation Models Know Geometry?（arXiv:2603.06459） | 冻结特征 + 6k 参数线性探针即可回归连续几何量（手关节角 MAE 6.1°），不同编码器精度相近 → 冻结基础特征含度量几何信息 |
| TabPFN v2（*Nature* 2025） | 表格基础模型，≤1 万样本回归默认即优于调参 4 h 的 CatBoost；农业（土壤属性）已有应用 |

**结论**：DINO 系特征已进入猪三维重建与农业回归，但**未检索到用于背膘/体况回归**，也未见用于**深度图**表型回归的系统比较 → 可做「RGB vs 深度伪彩 vs 两者，冻结 vs LoRA」对比，作为应用层贡献。

### 1.3 多视角融合（方向 3）

| 工作 | 融合方式 | 是否需要配准 |
|---|---|---|
| 胡宝玖 2025（本组） | 俯视 + 侧后视点云 FPFH-RANSAC 粗配准 + ICP 精配准 | **需要** |
| Pig3DNet GVQF（AIIA 2026） | 每视角几何可靠性打分 → 加权融合形状参数；偏重侧视 | 特征级免配准，但**尺度恢复需要标定外参** |
| Automated Cow BCS Using Multiple 3D Cameras（*Sensors* 2023, 23(22):9051） | 三台尾部附近深度相机各训一个 CNN，集成 | 不需要（决策级） |
| Agreement-Driven Multi-View 3D Reconstruction（arXiv:2601.17791） | SAM 3D 多视角潜空间一致性加权；R² 0.69（RGB-D 基线 0.65） | 不需要标定 |
| Beef cattle dual-view RGB weight（*Animals* 2026, 16(16):2532） | 双视角 RGB | — |
| Two-stream cross-attention ViT for RGB-D pig weight（CEA 2023） | **交叉注意力**融合 RGB 与深度两模态 | 模态融合，非视角融合 |

**结论**：「多视角加权/交叉注意力融合」都有先例。本课题能说的差异只有：**同猪两视角各为帧集合（不成对、帧数不同、无外参）**，集合间交叉注意力 + 视角随机丢弃直接融合，**替代胡宝玖的 ICP 配准**并正面对照。弱创新，放方法描述而非主贡献。

### 1.4 结构化信息 + 图像（方向 4）

| 工作 | 要点 |
|---|---|
| **Peng et al. 2025**, *Smart Agricultural Technology*（S277237552500108X） | 64 298 条记录，3 类别 + 18 数值特征，10 种 ML；XGBR/GBR 最优，妊娠 30/60/90 d/分娩背膘 **RMSE 1.17/1.09/1.01/0.81 mm**；最优分娩背膘 1 胎 18 mm、2 胎及以上 16 mm。**特征含此前的背膘测定值**，所以误差很低 |
| Pölsterl et al., **DAFT**（MICCAI 2021；NeuroImage 2022, 260:119505） | 表格数据生成缩放/偏移，调制 CNN 最后残差块特征图；优于拼接与单向 FiLM |
| FiLM（Perez et al., AAAI 2018） | 条件特征仿射调制 |
| Xiong et al.（*Transl. Anim. Sci.* 2023） | 深度图体积 + 牛龄等多输入做 BCS 分类 |

**结论**：
- 方法上 DAFT/FiLM 是现成的 → **借鉴**。
- **必须新增「纯表格基线」**：胎次 + 妊娠日龄 + 品系（+ 有则用历史背膘）→ XGBoost / TabPFN。否则会被问「图像比直接查生产记录多带来了什么」。
- 本课题数据：丰美禾 553 头有妊娠日龄、全部有胎次；102 头跨季重复，可构造「上一季背膘」特征 → 能复现 Peng 2025 的设定做对照。

## 2. 原 DV-MIL 框架的问题

1. **③ 帧级注意力 MIL 与肉牛 Episode-MIL（Animals 2026）几乎同构**，写成创新点会被直接指出。
2. **④ 视角质量加权融合**与 Pig3DNet GVQF 思路相同。
3. **⑤ FiLM/DAFT** 是 2018/2021 年的现成模块。
4. 原框架**缺少纯表格基线**：Peng 2025 用生产记录（含历史背膘）就能做到 RMSE≈1 mm，不对照则「视觉有什么用」会成为最大质疑。

## 3. 重新定位的创新点（检索未见先例，写作用「据检索所及」）

### 3.1 视觉相对生产记录的增量信息：先验–残差回归

- 结构：`背膘 = f_tab(胎次, 妊娠日龄, 品系[, 上次背膘]) + g_vis(图像 | 表格)`，视觉分支学习**偏离群体先验的残差**，调制借鉴 DAFT。
- 回答的问题（gComm 读者关心）：**在已有生产记录的前提下，视觉额外解释了多少背膘变异（ΔR²）？** 分胎次、分妊娠阶段报告。
- 已有工作要么只用表格（Peng 2025），要么只用图像（PigFormer、Jian），**未见两者增量关系的量化**。

### 3.2 带覆盖率保证的表型可信区间（保形预测）

- 在猪级交叉验证的校准折上做 Split Conformal / CQR，每头猪输出 90% 区间；报告实际覆盖率与区间宽度。
- 应用：区间过宽的个体自动标记「需 B 超复测」→「视觉初筛 + 超声复核」育种测定流程，量化可节省的 B 超次数。
- 畜禽表型回归中未检索到保形预测应用。

### 3.3 数据质量：标签匹配错误的量化（9/28 发现）

- 同一模型同一划分下，仅纠正标签：R² 0.083 → 0.297，CCC 0.17 → 0.45。
- 写成「表型数据治理」一节：多季重复测定下按耳号子串匹配导致约 1/3 标签错配；给出按测定日期分节匹配的规范。

### 3.4 统一评估协议下重评前期点云方法

- 同一猪级嵌套交叉验证下重跑胡宝玖 PointNet++ / PT-PnP（测试集选模 vs 验证集选模），加入 Sonata/PTv3 作为现代点云基线。
