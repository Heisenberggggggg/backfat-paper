# 双胞胎数据筛选标注说明（给标注同学）

> 原始数据**一张都不要删、不要移动**。所有判断只写进 `twins_index.xlsx`。

## 你要看的东西

`out_v1/sheets/` 里每段录像一张拼板图（在 xlsx 第 2 列点链接即可打开）：

- 30 个小图 = 从这段录像里均匀抽的 30 帧，左上角 `#数字` 是帧号
- 右下角小窗是深度图：**红 = 近，蓝 = 远，黑 = 没有深度**
- 红框 + `blur / no-depth / no-pig / dist` = 程序认为这一帧不能用（模糊 / 深度缺失 / 中央没拍到猪 / 距离异常），仅供参考，以你的判断为准
- 最底下的时间轴：绿线 = 清晰度，蓝线 = 画面中央距离，红竖线 = 程序判为坏帧，白三角 = 上面小图对应的位置

## 你要填的列（黄色表头）

| 列 | 怎么填 | 例 |
|---|---|---|
| 耳号 | 这段拍的母猪耳号（按现场记录） | 614169 |
| 背部帧段 | 镜头对着**背部**、猪完整清晰的帧 | `1-35` |
| 臀部帧段 | 镜头对着**臀部**、臀部轮廓完整清晰的帧 | `48-80` |
| 废弃帧段 | 明显不能用的：糊、拍到地面/墙/人、目标猪不在画面中央、被栏杆或邻猪挡住大半 | `36-47,150-159` |
| 可用(Y/N) | 这段有没有至少一段可用的背部或臀部 | Y |
| 标注人 | 你的名字 | |
| 备注 | 任何异常，如「邻栏猪入镜」「疑似两头猪」 | |

帧段写法：`起-止`，多段用英文逗号隔开，如 `1-20,30-45`。帧号以小图上的 `#数字` 为准，边界差几帧没关系。

## 特别注意

1. **一段录像可能拍了不止一头猪**（例如顶层文件夹 `1` 里连续拍了好几头，最后还拍到了墙上刷的编号「24」）。遇到这种情况：在 xlsx 里**复制这一行插在下面**，每头猪占一行，分别填耳号和帧段。
2. 拍到墙上 / 栏上的**编号牌**时，在备注里写下编号（这可能是对应耳号的线索）。
3. 拿不准就填 `?` 并在备注说明，不要猜。
4. 每人负责不同的分组（如 A 同学 `b、b2、bb`，B 同学 `c1–c4、cc`……），避免重复。
