## 一、项目概述

### 1.1 技术路线
```
RGB+Depth图像 (Azure Kinect, 俯视安装)
    ↓
YOLO11n 检测猪只位置 (目标检测)
    ↓
FastSAM-s 分割猪体掩膜 (实例分割)
    ↓
掩膜 + 深度图 + 相机内参 → 3D掩膜点云
    ↓
后处理: HDBSCAN去噪 → 统计滤波 → 体素下采样 → 中心化
    ↓
回归模型 → 背膘厚度预测 (mm)
```

### 阶段1: 环境搭建与基础流程验证 (2026-03-08 ~ 03-11)

#### 2.3 批处理脚本 (batch_process_all.py)
自动化处理多批次数据，支持断点续传、GPU显存自动清理。

**Bug修复 #1 — HDBSCAN预降采样**:
- 问题: 体素降采样公式对扁平点云计算出极大体素，282,652点只剩828点
- 原因: `voxel_size = (bbox_vol / 50000) ** (1/3)` 当Z轴范围很小时 bbox_vol 极小
- 修复: 改用随机子采样 `np.random.choice(len(points), 50000, replace=False)`

**Bug修复 #2 — 深度异常滤波器**:
- 新增Z坐标MAD滤波，去除栏杆点（与猪体深度不同）
- 效果: HDBSCAN去除0.9%噪声点, depth_outlier_filter去除5.9%栏杆点

### 阶段2: ABC路线对比实验 (2026-03-11 ~ 03-12)

#### 2.4 第一轮ABC对比 (V1 - 归一化点云, 仅nkyfirst 39头)

三条路线:
- **A**: 掩膜深度图(224x224) → 轻量CNN (86,785参数)
- **B**: 3D点云(1024点) → PointMLP (208,513参数)
- **C**: 点云统计/形态学特征 → GBR / SVR

评估: 5折交叉验证, 猪级别划分, 基线=猜均值(MAE≈2.20mm, R²=0.00)

| 路线 | MAE (mm) | R² |
|------|---------|-----|
| C-GBR | 2.08 | -0.02 |
| C-SVR | 2.11 | 0.05 |
| B-PointMLP | 2.13 | 0.03 |
| 猜均值基线 | ~2.20 | 0.00 |

**结论**: 所有模型预测均值，R²≈0。
**原因**: 单位球归一化消除了绝对尺寸信息。

#### 2.5 第二轮ABC对比 (V2 - 不归一化 + 全局特征 + 深度图)

改进: 1)只中心化不缩放; 2)加8维全局元特征; 3)新增路线A深度图CNN

| 路线 | MAE (mm) | RMSE (mm) | R² |
|------|---------|----------|-----|
| A-DepthCNN | 2.10 | 2.50 | 0.070 |
| B-PointMLP+Meta | 2.19 | 2.59 | -0.001 |
| C-SVR | 2.24 | 2.77 | -0.145 |
| C-GBR | 2.33 | 2.96 | -0.305 |

**结论**: 即使取消归一化，R²仍≈0。极端值预测严重偏差（真实10mm预测17mm, 真实22mm预测15mm）。

**Bug修复 #3 — FPS内存溢出**:
- 问题: 227k点直接做FPS导致OOM
- 修复: 先随机预降采样到5000点再FPS到1024

### 阶段3: PointMLP 专项训练 (2026-03-21 ~ 03-23)

用户决定不再做ABC对比，专注PointMLP路线，使用全部189头猪数据（4个数据源）。

#### 2.6 PointMLP v1 训练 (train.py)
- 参考官方 PointMLP 论文 (Ma et al., 2022) 从零实现 PointMLP-Elite
- 纯PyTorch实现FPS/KNN，无需编译 pointnet2_ops CUDA 扩展
- 参数量: 483,105
- 优化器: SGD (lr=0.01, momentum=0.9)
- 损失函数: SmoothL1Loss
- 归一化: 单位球归一化（中心化 + 除以最大距离）

**结果: 模型坍塌到预测均值**
- 所有预测收敛到 ~15.2mm（数据集均值）
- Test R² = -0.07, Test MAE = 2.72mm

**原因分析**:
1. SGD优化器 + SmoothL1Loss 组合在小样本回归上容易陷入局部最优（均值）
2. 单位球归一化丢失绝对尺寸信息
3. 参数量(48万) >> 独立样本量(189头), 容易过拟合

#### 2.7 PointMLP v2 训练 (train.py 修改)
三项改进:
1. SGD → **AdamW** (lr=1e-3, weight_decay=0.0002)
2. SmoothL1Loss → **MSELoss**（对大误差惩罚更强）
3. 单位球归一化 → **只中心化**（保留真实比例）

```python
# v1归一化（导致坍塌）:
centroid = np.mean(pc, axis=0)
pc = pc - centroid
max_dist = np.max(np.sqrt(np.sum(pc ** 2, axis=1)))
pc = pc / max_dist  # ← 丢失尺寸信息

# v2归一化（修复）:
centroid = np.mean(pc, axis=0)
pc = pc - centroid
# 不除以max_dist，保留真实比例
```

**结果: 过拟合**
- Train R² = 0.69, Val R² ≈ 0, Test R² = -0.22
- 模型"记住"了训练集每头猪的形状，但对新猪完全无效

#### 2.8 方案三: 传统ML + 手工统计特征 (extract_features.py + train_traditional.py)

**动机**: 深度学习在189头猪的小样本下表现不佳，尝试传统ML

**特征提取** (extract_features.py):
- 对189头猪的34,071帧点云提取41维统计特征
- 特征包括: 空间统计(xyz均值/标准差/偏度/峰度), Z分位数, 平面拟合残差, SVD/PCA比率, 凸包体积/面积, 点密度, 协方差矩阵
- 提取耗时: 417.8秒

**训练结果** (train_traditional.py):

| 模型 | 5-fold CV R² | Test R² | Test MAE | Test RMSE |
|------|-------------|---------|---------|----------|
| XGBoost | -0.03 ± 0.19 | **0.15** | **2.51mm** | **2.94mm** |
| 随机森林 | 0.10 ± 0.09 | 0.08 | 2.64mm | 3.06mm |
| Lasso回归 | -0.02 ± 0.01 | -0.09 | 2.80mm | - |

**关键发现**:
- XGBoost Test R²=0.15，首次超过猜均值基线！说明点云几何中**确实存在微弱的背膘信号**
- Lasso将41维特征全部置零（所有系数=0），说明单个特征与背膘的线性关系极弱
- XGBoost最重要特征: svd_ratio_2 (11.4%), 涉及点云主成分分析

#### 2.9 PointMLP v3: 方案一+二+四联合改进 (train_v3.py)

**方案一 — 强化数据增强**:
- Z轴随机旋转 (0-360°)
- 随机缩放 (0.85x-1.15x, 原来0.95-1.05x)
- 随机抖动 (σ=0.01, 原来0.005)
- 随机丢点 (概率0.5, 原来0.3)
- **新增**: 随机平移 (±5%), 随机镜像翻转 (X轴, 50%)

**方案二 — 缩减模型容量**:
- 通道数砍半: [64,128,256,512] → [32,64,128,256]
- embed_dim: 64 → 32
- 参数量: 483K → **125K** (减少74%)
- dropout: 0.5 → 0.6
- weight_decay: 0.0002 → 0.01

**方案四 — 混合特征**:
- PointMLP 全局特征 (128维) + 手工统计特征 (41维) → 拼接169维 → 回归头
- 手工特征从 `features_per_pig.csv` 加载

**结果**:

| 指标 | v2 | v3 | 改善 |
|------|-----|-----|------|
| Test R² | -0.06 | **0.15** | +0.21 |
| Test MAE | 2.72mm | **2.42mm** | -0.30mm |
| Test RMSE | 3.28mm | **2.94mm** | -0.34mm |
| 模型大小 | 5.97MB | **1.66MB** | 3.6x更小 |
| Best Epoch | 19 | 29 | 过拟合更慢 |
| MAPE | - | 16.7% | - |

**结论**: v3是目前最好的结果，R²=0.15与XGBoost持平，但仍然很弱——只解释了15%的方差。

| 实验 | 方法 | 数据量 | Test R² | Test MAE | 备注 |

### 3.2 核心结论
1. **点云几何中存在微弱的背膘信号**（R²=0.15），但信噪比很低
2. **单位球归一化是最大杀手** — 归一化后的实验全部R²≈0
3. **小样本（189头）是根本瓶颈** — 所有深度学习模型都过拟合
4. **传统ML在小样本下更稳定** — XGBoost几乎没有训练代码就达到了PointMLP v3三管齐下才达到的效果
5. **极端值预测能力差** — 背膘<12mm或>20mm的猪预测偏差最大

## 四、数据处理问题诊断与v2改进 (当前进行中)

### 4.1 发现的数据处理问题

经过以上所有实验后，回头审视整个数据处理流程，发现以下问题：

#### 问题一: 使用了整头猪，没有提取背部ROI
- **现状**: 保留头部(~13%)、背部(~64%)、臀部(~21%)三个点云块全部送入模型
- **问题**: 背膘在P2点（最后肋骨处）测量，头部/臀部形状与背膘无关，是噪声源
- **影响**: 模型需要从~34%的无关信息中找微弱信号，信噪比极低

#### 问题二: 同一头猪的多帧近乎重复
- **现状**: 每头猪~181帧点云（连续采集），帧间几何差异极小
- **问题**: 看似数据量大（几千文件），但独立样本只有189头。模型容易"认猪"
- **影响**: 训练集R²高（记住了每头猪），验证集R²低（新猪不认识）

#### 问题三: 单位球归一化丢失绝对尺寸
- **现状**: `postprocess_pointcloud.py` 的 `normalize()` 做了中心化+除以最大距离
- **问题**: 大猪小猪归一化后一样大，体型信息（与背膘相关）丢失
- **影响**: 所有使用归一化数据的实验R²≈0
- **部分修复**: v2/v3训练代码中绕过了归一化（从原始.ply加载），但仅2-1有原始.ply

#### 问题四: 分割质量未系统验证
- **现状**: 使用通用模型(yolo11n.pt + FastSAM-s.pt)做猪体分割，conf=0.15
- **问题**: 非专用猪检测模型，低置信度可能混入栏杆/地面点
- **影响**: 掩膜边界不精确，噪声混入猪体点云

### 4.2 v2 数据处理改进方案 (当前正在执行)

#### 新脚本1: generate_pointcloud_v2.py
- 遍历全部4个数据源的244头猪
- 自动读取每头猪的 intrinsic.json 获取相机内参
- **每头猪均匀抽20帧**（解决问题二: 181帧 → 20帧, 去除重复）
- 输出到 `masked_pointclouds_v2/`（不覆盖原数据）

#### 新脚本2: postprocess_pointcloud_v2.py
- HDBSCAN聚类 → **丢弃最小簇（头部）** → 保留背部+臀部（解决问题一）
- 统计滤波 → 体素降采样（4000-5000点）
- **只中心化，不做单位球归一化**（解决问题三）
- 输出到 `processed_pointclouds_v2/`
